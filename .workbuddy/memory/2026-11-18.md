# 2026-11-18

## 今日行动改版：行动类型 / 去掉额外生命力 / 历史最佳

改动文件：`index.html`、`forest.js`、`forest.css`（并重建 `dist/` 与 `dist/life-forest-preview.html`）。

**数据模型**
- 新增 `habit.weeklyTarget`（1–7）。`onlyOn` 仍表示日抛。
- `habitRepeat(habit)` 判定类型：`once`（有 onlyOn）→ `weekly`（weeklyTarget ≥ 1）→ `daily`（默认）。
- `readState` 用 `normalizeHabit` 归一化 weeklyTarget，兼容旧存档。

**行为**
- 周常：按自然周（周一起）统计 `weeklyDone`；达标后该行显示「本周 N/N · 已达标」、勾选态变暗、从「今日进度」分母中移除，再点只提示「下周继续」。
- 今日进度/今日可获得：只统计「今天仍待办」的行动（日常 + 日抛 + 未达标周常）。
- 删除 `awardDailyActionBonus` 与全部「完成全部行动额外 +1 生命力」逻辑；旧存档里的 bonus 记录保留（只做 prune 过滤，不再新增）。
- 底部统计改为：上行「历史最佳 M月D日 +N」（单日获得生命力最多的一天），下行「累计获得生命力 N」；右侧按钮由「连续完成天数」改为「历史情况」（仍打开行动日历）。
- 日历的「完成」标记改为：当天日常行动全部完成 = complete，否则 partial。

**编辑器**
- 重复频率改为 每天（日常行动）/ 每周（周常行动）/ 仅今天（日抛行动），选「每周」出现「每周目标次数 1–7」输入。

## 同日追加：编辑器同排 + 日均获得

- 编辑弹窗里「行动分类」「重复频率」合并到一行（`.action-field-row` 两列网格），下拉文案精简为 每天 / 每周 / 仅今天。
- 底部统计新增「日均获得」（`#action-average-line` / `#action-average`）：`actionHistory` 额外返回 `days` 与 `average`，按**有记录的天数**折算，整数直出、否则保留一位小数。
- 「日均获得」位置二次调整：不再作为 flex 兄弟悬浮在右侧，改为紧跟在 `#action-total-line` 同类后面，第二行读作「累计获得生命力 31 · 日均获得 7.8」；`#action-history-copy` 从 flex 改回 block，分隔点由 `#action-average-line::before` 生成。

## 同日追加：顶部统计口径拆分「今日 / 本周」

用户的诉求：周任务不该算进「今日进度」的分母，也不该算进「今日可获得生命力」（原来 1/5 与 +15 就是这么来的，且 +15 还把已完成的伊比理财算了进去）。

- 口径定案：**今日 = 日常行动 + 日抛行动**（今天真正到期、必须做的）；**周常 = 本周口径**，不占今日分母、不进今日可获得。
- `updateControls()` 重写统计段：`goal / completedCount / earnableReward` 只统计 `habitRepeat() !== "weekly"`；周常单独累计 `weekDone / weekGoal`（每项按 `min(本周已做, 目标)` 累加，达标部分不超计）。
- 顶部左侧 `.action-progress-count` 改成两行：`今日 1/3` + `本周 4/7`（`#action-week-line` / `#action-week-count`，无周常时 `hidden`）。
- 右侧胶囊由「今日可获得」改为「今日还可获得」，只算**今日到期且未完成**的奖励和；今日必做全做完时整块换成「今日行动 / 已全部完成」（`#action-total-done`），并加 `.is-empty` 弱化底色。注意 `replaceChildren` 拼接换行必须用 `document.createElement("br")`，直接传 `<br>` 字符串会原样显示。
- 叶子进度条改为 `Math.round(progress * 5)`，避免 1/3 时只亮 1 片显得滞后。
